# 차미 당도 연구소

> 📌 **[브이럽 공식 카페 배포 게시글 바로가기](https://cafe.naver.com/vlup?iframe_url_utf8=%2Fca-fe%2Fcafes%2F30653039%2Farticles%2F40609%253Fmenuid%3D153%2526oldPath%3D%252FArticleRead.nhn%253Fclubid%253D30653039%2526articleid%253D40609%2526menuid%253D153)** — 프로젝트 소개와 배포 안내를 게시글에서 확인할 수 있습니다.

Vite와 바닐라 JavaScript로 만든 미니게임 사이트입니다. 연구 기록은 브라우저 로컬 저장소에 보관하며, 서버에 DB 접속 정보가 있으면 백그라운드로 DB 동기화와 랭킹 요약 캐시 갱신을 시도합니다. DB가 없거나 사용할 수 없어도 로컬 기록과 게임은 계속 동작합니다.

## 실행

Node.js 20.6 이상이 필요합니다. DB 접속 정보 없이도 실행할 수 있습니다.

```sh
npm install
npm run dev
```

개발 실행은 Vite와 Node.js 서버를 함께 시작합니다. `.env.local`에 `DATABASE_URL`(또는 지원되는 Postgres URL)이 있으면 서버가 DB 동기화 API를 활성화합니다. 설정이 없거나 DB 연결에 실패하면 브라우저 로컬 기록만 사용합니다.

## 배포

> **팬게임 배포 주의:** [현재 배포 게시글](https://cafe.naver.com/vlup?iframe_url_utf8=%2Fca-fe%2Fcafes%2F30653039%2Farticles%2F40609%253Fmenuid%3D153%2526oldPath%3D%252FArticleRead.nhn%253Fclubid%253D30653039%2526articleid%253D40609%2526menuid%253D153)은 브이럽 공식 카페에서 확인할 수 있습니다. 아래 명령은 기술적인 실행 방법일 뿐, 공개·배포 허가를 뜻하지 않습니다. 프로젝트에 보관한 [V-LUP 팬게임 지침](VLUP_GUIDELINE.md)에 따르면 무료 배포는 브이럽 공식 카페에 한정되며 광고 수익이 발생하는 호스팅·배포 페이지 이용은 금지됩니다. 베타를 포함해 공개하기 전에 배포 링크와 설명을 사전 통보해야 합니다. 현재 Vite·Node.js·DB 구성물을 일반 호스팅에 게시하기 전에 최신 공식 지침과 허가 여부를 확인하세요.

정적 파일 호스팅 또는 Node.js 서버에서 실행할 수 있습니다. Node.js 서버 방식은 다음 명령을 사용합니다.

```sh
npm install
npm run build
npm start
```

Node.js 서버에서는 `PORT` 환경 변수를 사용하며 기본 포트는 4173입니다. Vercel 배포에서는 프로젝트 루트의 `api/sync.js`가 DB 동기화 API를 제공합니다. 브라우저는 DB에서 받은 상위 50개 순위·점수·차미 획득 수·등급 요약을 별도 로컬 저장 키에 보관합니다. 랭킹 모달은 이 캐시를 즉시 표시하고, 백그라운드 동기화로 캐시가 갱신되면 열린 화면도 함께 업데이트합니다. 랭킹 자료를 한 번이라도 받아 캐시에 저장한 뒤에는 DB 연결이 끊겨도 저장된 순위를 계속 볼 수 있습니다. 아직 랭킹 자료를 받은 적이 없으면 랭킹 보기 버튼이 회색으로 비활성화되며, 시트리 당도 연구카드와 로컬 게임 기록은 계속 사용할 수 있습니다.

Vercel에서 DB 동기화를 쓰려면 프로젝트의 **Settings → Environment Variables**에서 `DATABASE_URL`을 Production 환경 변수로 등록하고 새 배포를 만들어야 합니다. `.env.local`은 로컬 전용이며 Vercel에 자동 전송되지 않습니다.

## 방문자와 저장 데이터

- 당도 연구와 미니게임 기록은 기존 브라우저 로컬 저장소에 계속 저장합니다. DB가 활성화된 서버에 연결되면 같은 출처의 익명 식별 쿠키를 사용해 해당 기록을 백그라운드로 전송하고, 서버는 쿠키 원문 대신 해시를 저장합니다. 쿠키는 동기화에 성공할 때마다 수명이 1년으로 연장되어 브라우저를 닫았다 다시 열어도 같은 익명 방문자로 이어집니다.
- 서버 DB에는 익명 세션별 연구 기록(획득한 당도왕 차미 목록 포함)과 총점이 저장됩니다. 같은 세션 쿠키로 식별되는 DB 연구 기록은 기존 방문자 기록으로 불러와 브라우저 로컬 기록과 합친 뒤 다시 저장합니다. 누적 횟수와 점수, 최고 수치는 큰 값으로 합치고 기억 게임 최고 기록은 더 적은 이동 수를 유지하며 당도왕 차미는 같은 모양을 다시 얻어도 매번 획득 수에 포함합니다. 로컬·DB 병합 시에는 모양별 획득 횟수 중 큰 값을 유지해 정상적인 반복 획득을 보존하고 같은 기록의 재전송은 중복 가산하지 않습니다. 브라우저에는 DB에서 받은 상위 50개 익명 순위·점수·당도왕 차미 획득 수·등급과 내 기록 요약이 별도 랭킹 로컬 저장 키로 저장됩니다. 게임 기록이 저장되면 백그라운드 동기화를 예약합니다. 연구카드나 랭킹 모달을 열 때는 저장된 기록을 즉시 표시하고, 1초 예약·최소 동기화 간격·브라우저 유휴 시간 대기 없이 DB 동기화를 시작합니다. 기존에 예약된 타이머나 유휴 콜백은 취소하며, 이미 진행 중인 동기화와 새 요청을 동시에 실행하지 않습니다. 모달은 DB를 직접 조회하지 않고 캐시를 표시하며, 동기화로 캐시가 바뀌면 열린 모달도 갱신됩니다. DB 동기화 실패는 게임과 로컬 저장에 영향을 주지 않습니다. 랭킹 캐시가 있으면 버튼과 저장된 랭킹을 계속 사용할 수 있고, 아직 캐시가 없을 때는 버튼이 비활성화됩니다.
- 랭킹에 반영되는 총점과 당도왕 차미 획득 수는 브라우저·DB 병합 기록을 바탕으로 하며 서버가 부정 플레이를 검증하지 않으므로, 랭킹은 참고용 기록입니다. 랭킹에는 익명 순위·점수·차미 획득 수·등급만 표시합니다.
- 이전 버전은 동일한 이미지 경로의 획득 목록을 하나로 줄여 재접속·동기화 때 획득 수가 감소할 수 있었습니다. 수정 후에는 남아 있는 로컬·DB 획득 목록의 반복 획득을 보존합니다. 이미 양쪽에서 제거된 과거 획득 항목은 정확한 횟수를 알 수 없어 자동 보정하지 않습니다.
- 브라우저 저장 공간을 지우면 로컬 기록과 랭킹 캐시가 삭제되지만 익명 쿠키가 남아 있으면 다음 동기화에서 DB 기록을 복원할 수 있습니다. 쿠키를 삭제하거나 1년 동안 동기화하지 않아 만료되면 다음 접속은 새 익명 방문자로 구분되며 기존 DB 기록과 자동으로 연결되지 않습니다. DB의 기존 기록은 자동 삭제되지 않습니다.
- DB 동기화는 `DATABASE_URL` 등 Postgres 접속 설정이 있는 Node.js 서버 또는 Vercel Function에서 사용할 수 있습니다. 정적 호스팅이나 배포 환경 변수 미설정 환경에서는 로컬 기록만 사용합니다.

`.env.local`은 로컬 개발 전용으로 선택 사항입니다. Vercel 배포 환경은 프로젝트 설정에서 별도로 DB 환경 변수를 관리합니다.

## 게임과 기록

- 당도 팡은 차미 표본 6개를 각 1~5회 팡팡 눌러 모두 완료하면 당도 결과를 공개합니다. 모은 당도왕 차미 수만큼 위성 차미가 시트리 요정을 따라다니며, 새로 얻은 차미는 뒤에 이어집니다. 이 수는 로컬·DB 병합 기록을 바탕으로 접속할 때마다 복원되며 같은 모양을 여러 번 얻은 수도 포함합니다. 미니게임으로는 정밀 측정, 기포 제거, 도망 차미 포착, 표본 짝맞추기와 두더지 차미 팡, 표정 레이더, 설탕 균형탑, 차미 핑퐁을 제공합니다. 짝맞추기는 16장(8쌍)과 한 판당 3회의 2초 전체 보기 힌트가 있고, 핑퐁은 포인터나 좌우 방향키로 플레이합니다.
- 차미 캐릭터 이미지는 AI로 새로 생성했으며, 당도왕 차미는 미니 시트리 뒤를 따라가는 위성 캐릭터로도 등장합니다.
- 별도 업적·배지 목록은 없습니다. 게임 결과를 브라우저 로컬 저장소의 누적 점수로 계산하며, 당도왕 차미 획득 목록도 로컬 저장소에 누적·보존합니다. `시트리 당도 연구카드` 모달에서 기존 연구 기록 3개, 얻은 당도왕 차미 수, 총점, 실버·골드·플래티넘·다이아·마스터 등급 트로피를 확인할 수 있습니다. 세부 점수 기준은 화면에 표시하지 않습니다.
- 당도 연구나 점수를 주는 미니게임 결과가 반영되면, 획득 점수와 누적 점수를 알려주는 반응형 토스트가 화면에 잠시 표시됩니다. 차미 팡팡에서 당도왕 차미가 새로 합류할 때도 획득 마리 수와 현재 화면에 합류한 차미 수를 알리는 별도 토스트가 표시됩니다. 체류 시간으로 쌓이는 점수는 토스트를 띄우지 않습니다.
- 넓은 화면의 히어로 시트리를 빠르게 연속으로 누르면 5회째에 가벼운 경계 대사와 붉은 말풍선이 표시됩니다. 경고 뒤에도 빠르게 5회 더 누르면 더 진한 붉은 말풍선과 2단계 대사로 바뀝니다. 이 2단계에 들어간 뒤 5초 안에 15회 이상 더 누르면 이스터에그 3단계 대사와 조금 더 큰 검붉은 글씨가 나타납니다. 클릭할 때마다 대사 게이지가 다시 시작되며, 게이지가 끝나면 단계와 대사가 기본 상태로 돌아옵니다. 모바일에서는 기존처럼 히어로 대사 카드를 표시하지 않습니다. 요정 시트리의 반응은 별도 토글로 켜고 끌 수 있습니다.

## 주요 파일

- `src/main.js`: 게임 화면과 브라우저 동작
- `src/style.css`: 반응형 UI와 애니메이션
- `server.js`: 정적 파일 서버와 선택형 백그라운드 DB 동기화 API
- `db/schema.js`: 방문자·연구 기록 및 랭킹용 DB 스키마
- `shared/earned-chamis.js`: 브라우저·서버 공통 차미 목록 검증 및 획득 횟수 병합
- `test/earned-chamis.test.js`: 반복 획득·재접속·재동기화 회귀 검사 (`npm test`)
- `vite.config.js`: 개발 환경 API 프록시
- `VLUP_GUIDELINE.md`: V-LUP 팬게임 지침 전문 보관본
