# 차미 당도 연구소

Vite와 바닐라 JavaScript로 만든 팬게임 웹 프로젝트입니다. 시트리의 CSS 살랑 모션, 무작위 차미 당도 측정, 당도계 눈금 맞추기, 차미 기포 빼기, 연구 배지 수집 기능이 들어 있습니다.

## 시작하기

```sh
npm install
npm run dev
```

## 빌드 및 미리보기

```sh
npm run build
npm run preview
```

- 게임 동작과 화면: `src/main.js`
- 반응형 스타일과 모션: `src/style.css`
- 생성 이미지: `public/images/`
- 연구 기록과 배지: 브라우저 `localStorage`에 저장됩니다.
