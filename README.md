# 차미 당도 연구소

Vite와 바닐라 JavaScript로 만든 미니게임 사이트입니다. 연구 기록은 브라우저 로컬 저장소에 보관합니다. 서버 DB 연결은 비활성화되어 있습니다.

## 실행

Node.js 20.6 이상이 필요합니다. DB 접속 정보 없이 실행할 수 있습니다.

```sh
npm install
npm run dev
```

개발 실행은 Vite와 정적 파일 서버를 함께 시작합니다. 기록은 현재 브라우저에만 저장되며 다른 기기나 브라우저와 동기화되지 않습니다.

## 배포

> **팬게임 배포 주의:** 아래 명령은 기술적인 실행 방법일 뿐, 공개·배포 허가를 뜻하지 않습니다. 프로젝트에 보관한 [V-LUP 팬게임 지침](VLUP_GUIDELINE.md)에 따르면 무료 배포는 브이럽 공식 카페에 한정되며 광고 수익이 발생하는 호스팅·배포 페이지 이용은 금지됩니다. 베타를 포함해 공개하기 전에 배포 링크와 설명을 사전 통보해야 합니다. 현재 Vite·Node.js·DB 구성물을 일반 호스팅에 게시하기 전에 최신 공식 지침과 허가 여부를 확인하세요.

정적 파일 호스팅 또는 Node.js 서버에서 실행할 수 있습니다. Node.js 서버 방식은 다음 명령을 사용합니다.

```sh
npm install
npm run build
npm start
```

서버는 `PORT` 환경 변수를 사용하며 기본 포트는 4173입니다. DB 프로필 API는 비활성화되어 있으며 브라우저 저장소만 사용합니다.

## 방문자와 저장 데이터

- 당도 연구와 미니게임 기록을 브라우저 로컬 저장소에 저장합니다.
- 브라우저 데이터나 사이트 저장 공간을 지우면 기록도 삭제됩니다.
- 기록은 서버로 전송되거나 다른 브라우저와 공유되지 않습니다.

`.env.local`은 현재 실행에 필요하지 않습니다.

## 게임과 기록

- 당도 팡은 무작위 차미 표본 6개의 당도를 측정합니다. 정밀 측정, 기포 제거, 도망 차미 포착, 표본 짝맞추기도 제공하며, 짝맞추기는 시작 전부터 섞인 8장(4쌍)이 보이고 4열 카드로 플레이합니다.
- 별도 업적·배지·트로피 달성 시스템은 없습니다. 하단 `트로피` 항목의 `시트리 당도 연구카드 보기` 버튼을 누르면 브라우저에 저장된 연구 횟수·최고 기록과 단일 트로피를 모달에서 확인할 수 있습니다.

## V-LUP 팬게임 가이드라인

- 이 프로젝트는 AI 에이전트를 활용해 구현·수정했습니다. 에이전트가 작업할 때마다 [AGENTS.md](AGENTS.md)의 절차에 따라 [V-LUP 지침 사본](VLUP_GUIDELINE.md)과 변경 내용을 대조하고, AI 사용·콘텐츠·배포 관련 사실이 바뀌면 사이트 이용 가이드와 문서도 함께 갱신하도록 안내합니다. 이 검토 장치는 작업 지침이며, 공식 승인이나 준수를 보증하지 않습니다.
- [VLUP_GUIDELINE.md](VLUP_GUIDELINE.md)에 요청자가 제공한 팬게임 제작·배포 지침 전문과 원문 링크를 보관합니다.
- 사이트 하단 고정 메뉴의 `이용 가이드` 버튼에서 주요 내용을 확인할 수 있습니다. AI 생성 이미지 표기와 시트리 의상 참고 출처는 사이트 푸터에 표시합니다. 트로피는 연구카드 모달 안에 단일 장식 항목으로 표시하며 별도 달성·보상 시스템은 없습니다.
- 프로젝트 참고 출처: [의상 참고 VOD](https://vod.sooplive.com/player/209820895), [시트리의 숲 공식 방송국](https://www.sooplive.com/station/vlupsitry)
- 사이트 이용 가이드에는 AI 사용 내역을 O/X로 표시합니다. 시트리·차미 팬 이미지 생성 및 문구·기획·코드 보조는 사용(O), 음성·음악·효과음·영상 생성과 프로젝트 자체 모델 학습은 미사용(X)으로 구분했습니다. 상세 범위와 에셋 출처는 [프로젝트 AI 사용 내역](VLUP_GUIDELINE.md#프로젝트의-ai-사용-내역-v-lup-원문-아님)을 참고하세요.
- 사이트 표기는 시트리와 차미를 기본으로 합니다. 차미는 별도의 공식 영문 키워드가 없어 영문 이름 표기를 사용하지 않습니다.
- 문서 사본이 최신인지 공개 전에 [공식 원문](https://cafe.naver.com/vlup/36148)에서 확인하고, 변경되면 이 문서와 사이트 안내를 함께 갱신하세요. 이 프로젝트 문서와 UI는 사전 통보나 배포 승인을 대신하지 않습니다.

## 주요 파일

- `src/main.js`: 게임 화면과 브라우저 동작
- `src/style.css`: 반응형 UI와 애니메이션
- `server.js`: 정적 파일 서버와 비활성화된 저장 API 응답
- `db/schema.js`: 기존 DB 스키마 참고 파일
- `vite.config.js`: 개발 환경 API 프록시
- `VLUP_GUIDELINE.md`: V-LUP 팬게임 지침 전문 보관본
