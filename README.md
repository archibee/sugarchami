# 차미 당도 연구소

Vite와 바닐라 JavaScript로 만든 미니게임 사이트입니다. 익명 방문 쿠키로 방문자를 구분하고 PostgreSQL에 연구 기록과 트로피를 저장합니다.

## 실행

Node.js 20.6 이상이 필요합니다. 프로젝트 루트의 `.env.local`에 `DATABASE_URL`을 설정한 뒤 실행합니다.

```sh
npm install
npm run dev
```

개발 실행은 Vite와 API 서버를 함께 시작합니다. API 서버가 시작될 때 `db/schema.js`을 적용합니다. 스키마는 반복 적용해도 기존 기록을 삭제하지 않습니다.

## 배포

> **팬게임 배포 주의:** 아래 명령은 기술적인 실행 방법일 뿐, 공개·배포 허가를 뜻하지 않습니다. 프로젝트에 보관한 [V-LUP 팬게임 지침](VLUP_GUIDELINE.md)에 따르면 무료 배포는 브이럽 공식 카페에 한정되며 광고 수익이 발생하는 호스팅·배포 페이지 이용은 금지됩니다. 베타를 포함해 공개하기 전에 배포 링크와 설명을 사전 통보해야 합니다. 현재 Vite·Node.js·DB 구성물을 일반 호스팅에 게시하기 전에 최신 공식 지침과 허가 여부를 확인하세요.

정적 파일만 올리는 호스팅 대신 Node.js 서버를 실행할 수 있는 호스팅을 사용합니다. 배포 환경 변수에 `DATABASE_URL`을 등록하고 다음 명령으로 실행합니다.

```sh
npm install
npm run build
npm start
```

서버는 `PORT` 환경 변수를 사용하며 기본 포트는 4173입니다. `npm run preview`는 정적 Vite 미리보기만 실행하므로 API와 DB 저장이 필요한 배포 확인에는 `npm start`를 사용합니다.

## 방문자와 저장 데이터

- 서버는 400일 만료의 `HttpOnly`, `SameSite=Lax` 익명 쿠키를 발급합니다. HTTPS에서는 `Secure`도 설정합니다.
- DB에는 쿠키 원문 대신 SHA-256 해시를 저장합니다. 쿠키를 지우면 새 방문자로 시작합니다.
- 당도 연구와 세 미니게임 기록, 14개 트로피 달성 시각을 PostgreSQL에 저장합니다.
- 브라우저 로컬 저장소는 API를 사용할 수 없을 때의 임시 기록으로만 씁니다. 서버에 연결되면 해당 쿠키 방문자의 DB 기록을 표시합니다.
- 게임 기록은 로그인 없이 전송되므로 보안상 신뢰 가능한 경쟁 점수나 보상으로 사용하면 안 됩니다.

`.env.local`은 Git에서 제외되어 있습니다. DB 접속 정보를 클라이언트 코드나 `VITE_` 환경 변수에 넣지 마세요.

## V-LUP 팬게임 가이드라인

- [VLUP_GUIDELINE.md](VLUP_GUIDELINE.md)에 요청자가 제공한 팬게임 제작·배포 지침 전문과 원문 링크를 보관합니다.
- 사이트 하단 고정 메뉴의 `이용 가이드` 버튼에서 주요 내용을 확인할 수 있습니다. AI 생성 이미지 표기와 시트리 의상 참고 출처는 사이트 푸터에 표시합니다. 업적 카드 기능은 사이트 안에서 보기만 제공하며 파일 저장 기능은 제공하지 않습니다.
- 프로젝트 참고 출처: [의상 참고 VOD](https://vod.sooplive.com/player/209820895), [시트리의 숲 공식 방송국](https://www.sooplive.com/station/vlupsitry)
- 사이트 이용 가이드에는 AI 사용 내역을 O/X로 표시합니다. 시트리·차미 팬 이미지 생성 및 문구·기획·코드 보조는 사용(O), 음성·음악·효과음·영상 생성과 프로젝트 자체 모델 학습은 미사용(X)으로 구분했습니다. 상세 범위와 에셋 출처는 [프로젝트 AI 사용 내역](VLUP_GUIDELINE.md#프로젝트의-ai-사용-내역-v-lup-원문-아님)을 참고하세요.
- 사이트 표기는 시트리와 차미를 기본으로 합니다. 디자인 장식에는 SITRY를 사용하며, 차미는 별도의 공식 영문 키워드가 없어 영문 이름 표기를 사용하지 않습니다.
- 문서 사본이 최신인지 공개 전에 [공식 원문](https://cafe.naver.com/vlup/36148)에서 확인하고, 변경되면 이 문서와 사이트 안내를 함께 갱신하세요. 이 프로젝트 문서와 UI는 사전 통보나 배포 승인을 대신하지 않습니다.

## 주요 파일

- `src/main.js`: 게임 화면과 브라우저 동작
- `src/style.css`: 반응형 UI와 애니메이션
- `server.js`: 익명 방문자 쿠키, API, PostgreSQL 연결
- `db/schema.js`: 방문자, 연구 통계, 트로피 테이블
- `vite.config.js`: 개발 환경 API 프록시
- `VLUP_GUIDELINE.md`: V-LUP 팬게임 지침 전문 보관본
