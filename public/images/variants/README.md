# Character image variants

PNG assets for future mini-game, dialogue, collection, and reward UI use.
All generated character images use transparent backgrounds.

## Chami

The 18 individual 512 × 512 sprites are ready to use directly:

- Expression set A: `chami-cheerful`, `chami-sleepy`, `chami-determined`, `chami-surprised`, `chami-dozy`, `chami-sparkle`
- Expression set B: `chami-cheering`, `chami-yawning`, `chami-curious`, `chami-bashful`, `chami-grumpy`, `chami-dizzy`
- Leaf and silhouette set: `chami-triple-leaf`, `chami-curled-leaf`, `chami-double-sprout`, `chami-mint-leaf`, `chami-dew-leaf`, `chami-pear-shape`

The original 3 × 2 sheets are kept alongside the individual sprites as `chami-expressions-atlas-a.png`, `chami-expressions-atlas-b.png`, and `chami-leaf-variants-atlas.png`.

## Sitri

- `sitri-wave-mascot.png`: welcoming wave
- `sitri-pointing-mascot.png`: points toward a game or panel
- `sitri-trophy-mascot.png`: celebrates a trophy
- `sitri-sugar-meter-mascot.png`: reacts to a sugar-meter result
- `sitri-sd-actions-atlas.png` and `sitri-sd-expressions-atlas.png`: additional four-pose SD sheets

All paths are relative to `/images/variants/` when served by Vite.
